# RouterMonitor

אפליקציית אנדרואיד שמציגה בזמן אמת אילו מכשירים מחוברים לראוטר ASUS ומה רוחב הפס של כל אחד.

## התקנה
בכל שינוי בקוד, GitHub בונה את האפליקציה אוטומטית. את הגרסה האחרונה מורידים מ־**Releases** ← `RouterMonitor.apk`.

## דרישות
- הטלפון מחובר ל־Wi‑Fi של הבית.
- כדי לראות רוחב פס לכל מכשיר, צריך להפעיל בראוטר **Adaptive QoS** או **Traffic Analyzer**.
- בהפעלה הראשונה מזינים את כתובת הראוטר (ברירת מחדל 192.168.1.1), שם משתמש וסיסמה.
